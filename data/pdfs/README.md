# Futurs documents pédagogiques

Ce dossier accueillera les futurs PDF pédagogiques du projet.

Règles :

- ne jamais y placer de données personnelles ou de copies d'élèves ;
- vérifier les droits d'utilisation des documents ;
- suivre les fichiers volumineux avec DVC plutôt qu'avec Git ;
- documenter la provenance, la licence et la date d'ajout de chaque document ;
- prévoir une extraction accessible et une description textuelle des contenus visuels.

Aucun PDF réel n'est inclus à cette étape.
