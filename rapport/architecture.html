RAG Pipeline (index the course, create quiz content)

GenAI + RAG part
  1. Load course files PDF / MD from DVC
  2. Read pages, extract text + images PyMuPDF
  3. Chunking 800 chars, overlap 150
  4. Embeddings multilingual-e5-small
  5. Vector + keyword index ChromaDB + BM25
  6. Quiz generation hybrid search (RRF) + gpt-oss-120b, prompts v5
  7. Evaluation LLM judge, hit@5, citations, readability
  8. Log to MLflow
  9. Produce RAG manifest
