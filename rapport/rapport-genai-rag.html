Projet Tuteur éducatif inclusif · module GenAI + RAG · octobre 2026

Un tuteur qui répond à partir du cours, cite la bonne page et n'invente rien

Le module transforme un cours (PDF, texte) en réponses, quiz et remédiations, en version standard et simplifiée (FALC). Résultats de la dernière version (v5) sur 16 questions de référence :

Fonctionnement et paramètres choisis

Le pipeline RAG, étape par étape

RAG : avant de répondre, on cherche les passages utiles du cours, et le modèle ne répond qu'avec eux.

1

Lecture

Outil
PyMuPDF
Unité
page par page

Garder la page permet de citer la source. Les images sont extraites pour le module Inclusion.

2

Découpage

Taille
800 caractères
Chevauchement
150 caractères

Coupe aux paragraphes puis aux phrases. Le chevauchement évite de couper une idée en deux.

3

Embeddings

Modèle
multilingual-e5-small
Base
ChromaDB, cosinus

Bon en français, petit, tourne sur CPU. ChromaDB est locale, sans serveur.

4

Recherche hybride

Sens + mots
dense + BM25
Fusion
RRF k=60, 20 candidats
Gardés
top 5

BM25 trouve les mots exacts (« 5 à 10 quiz ») que les embeddings ratent.

5

Génération

LLM
gpt-oss-120b (Groq)
Température
0.3
Sortie
JSON validé

Gratuit, sans GPU. Prompts en YAML versionnés. Un quiz mal formé est redemandé.

6

Garde-fou

Contrôle
chaque [p. N]
Action
retire les pages fausses

Une fausse page montrée à un élève est pire que pas de citation.

Évaluation : un juge LLM d'une autre famille (qwen3.8-27b) note les réponses, pour éviter qu'un modèle se note lui-même.
